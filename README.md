Journey Haven International Travel Agencies Website

A responsive website for Journey Haven International Travel Agencies, designed to showcase international recruitment services, visa processing support, travel arrangements, and overseas job opportunities.

The website helps prospective applicants learn about the agency, explore job sectors, understand the application process, contact the team, and submit their application details through WhatsApp.

Project Overview

Project Name: Journey Haven International Travel Agencies

Website Type: Recruitment, visa support, and travel agency website

Location: Unicity Mall, Thika Road, Nairobi, Kenya

Primary Destination: Dubai and the United Arab Emirates (UAE)

Purpose: To provide information about the agency's services and make it easier for prospective applicants to inquire about overseas employment opportunities.

Features
Responsive Design: Adapts to desktop, tablet, and mobile screens.
Modern User Interface: Clean layout, custom typography, and a professional color scheme.
Services Section: Highlights international recruitment, visa processing support, travel and relocation, and travel packages.
Application Process: Explains the four main steps: registration, interview, visa processing, and travel.
Job Sectors: Displays security, warehousing, hospitality, cleaning services, and agriculture and greenhouse opportunities.
WhatsApp Application Form: Collects applicant details and prepares a WhatsApp message for the agency.
Direct Contact Links: Enables visitors to call the agency using their mobile devices.
WhatsApp Chat Button: Provides quick access to WhatsApp from any section of the page.
Social Media Links: Links to Facebook, Instagram, and TikTok.
Office Information: Displays the agency's address and opening hours.
Google Maps Directions: Provides a link for finding the agency's office.
Mobile Navigation Menu: Includes a collapsible navigation menu for smaller screens.
Accessibility Support: Includes accessible labels, keyboard focus indicators, and reduced-motion support.
Dark Mode Support: Supports system dark mode and an explicit dark theme setting.
Technologies Used
HTML5 — Website structure and content.
CSS3 — Styling, responsive layouts, animations, and theme support.
JavaScript — Mobile navigation, WhatsApp integration, and form handling.
Google Fonts — Bricolage Grotesque and DM Sans.
WhatsApp Click to Chat — Opens WhatsApp with prefilled messages.
Google Maps — Provides directions to the office.

No frontend framework or package manager is required for the current implementation.

Getting Started
Prerequisites

You need:

A modern web browser, such as Google Chrome, Microsoft Edge, Firefox, or Safari.
A code editor, such as Visual Studio Code, for editing the website.
An internet connection for Google Fonts, Google Maps, social links, and WhatsApp functionality.
Installation
Create a project folder named journey-haven.
Save the supplied website code in a file named index.html.
Save this documentation as README.md in the same folder.
Open index.html in your browser.
Run with Visual Studio Code

For local development, open the project folder in Visual Studio Code and use the Live Server extension to preview the website.

Alternatively, open index.html directly
